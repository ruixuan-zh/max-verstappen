# Max Verstappen the COE Tracker and Predictor

Final Goal: A web app for tracking and predicting Singapore COE prices using historical bidding data and current events.


## Planned Features
- View historical COE prices
- Track COE bidding results by category
- Analyse price trends
- Predict future COE prices
- Display relevant market and policy events

## Tech Stack (to be finalised)
- frontend: Next.js + React
- backend: Python
- Database: PostgreSQL
